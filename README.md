## Active Focus

These are the projects receiving my attention.

### [Voidworks](https://github.com/LeTrollologist/Voidworks)

[![Repository](https://img.shields.io/badge/OPEN_REPOSITORY-Voidworks-38BDF8?style=for-the-badge&logo=github&logoColor=white&labelColor=0f172a)](https://github.com/LeTrollologist/Voidworks)
![Active](https://img.shields.io/badge/STATUS-Active-10B981?style=for-the-badge&labelColor=0f172a)

A 2D simulation game inspired heavily by *RimWorld* and *Space Station 13*. The priority is building a reliable simulation foundation before expanding the game's content.

### [Morrow](https://github.com/LeTrollologist/Morrow)

[![Repository](https://img.shields.io/badge/OPEN_REPOSITORY-Morrow-8B5CF6?style=for-the-badge&logo=github&logoColor=white&labelColor=0f172a)](https://github.com/LeTrollologist/Morrow)
![Resuming](https://img.shields.io/badge/STATUS-Resuming_Work-10B981?style=for-the-badge&labelColor=0f172a)
![RBMM](https://img.shields.io/badge/RBMM-ALGEBRAIC_EFFECTS-06B6D4?style=for-the-badge&labelColor=0f172a)

A systems-level programming language featuring Region-Based Memory Management (RBMM) and Algebraic Effects. After roughly a month away from development, it's time to return to it and push the language toward completion.

### [Statecraft](https://github.com/LeTrollologist/Statecraft)

[![Repository](https://img.shields.io/badge/OPEN_REPOSITORY-Statecraft-38BDF8?style=for-the-badge&logo=github&logoColor=white&labelColor=0f172a)](https://github.com/LeTrollologist/Statecraft)
![Active](https://img.shields.io/badge/STATUS-Active-10B981?style=for-the-badge&labelColor=0f172a)
![DLC](https://img.shields.io/badge/NEXT-DLC_Support-F59E0B?style=for-the-badge&labelColor=0f172a)

A Suzerain Lua inspection and trainer tool. The core project is active, with support for upcoming DLC planned.
